# M10 Modbus TCP Monitor

Демонстрационная программа для Windows: чтение показаний двух M10 по MODBUS TCP и сравнение с WEB-экраном приборов.

## Сборка и автономный EXE

**Microsoft Visual Studio Community 2022, версия 17.14** — [скачать с сайта Microsoft](https://visualstudio.microsoft.com/vs/older-downloads/). В установщике выбрать **«Разработка классических приложений .NET»** и **.NET 8 SDK**. Это Visual Studio, не Visual Studio Code.

Открыть в IDE файл **`M10Modbus.sln`**. Для обычной сборки выбрать **Release**, затем **Сборка → Собрать решение**; для запуска — **F5**.

Чтобы получить EXE для **Windows x64 без доустановки .NET**, открыть **Вид → Терминал** в Visual Studio и выполнить из папки решения:

```powershell
dotnet publish M10Modbus.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

Готовый файл — **`publish\M10Modbus.exe`**. Его можно перенести на другой ПК с Windows 10/11 x64: среда .NET включена в EXE. Обычная сборка через меню такой автономный EXE не создаёт.

## Подключение через VPN

**Адреса `10.0.1.8` и `10.0.1.18` зашиты по умолчанию для конкретного стенда:** программа предназначена для запуска при установленном VPN-подключении в локальную подсеть **из двух приборов M10 с этими адресами**. Это объявленные адреса данного стенда, а не универсальные адреса любых M10.

После подключения VPN проверить приборы последовательно:

1. В командной строке Windows:
   ```cmd
   ping 10.0.1.8
   ping 10.0.1.18
   ```
2. Открыть в двух окнах браузера **[https://10.0.1.8/](https://10.0.1.8/)** и **[https://10.0.1.18/](https://10.0.1.18/)**. Если для стенда выдан отдельный WEB-порт или путь, использовать выданный полный URL.
3. Запустить программу, проверить **IP, порт MODBUS (обычно 502), Id и канал весов**, затем нажать **«Начать опрос»** в каждой карточке. Номер карточки не является номером канала: если в каждом M10 одни весы, канал в обеих карточках — **1**. Все поля должны соответствовать настройкам приборов.

**Снимок для сравнения:** разместить рядом обе WEB-страницы (два окна браузера) и окно программы так, чтобы были видны показания всех трёх окон; сохранить общий снимок в PNG.

## Что читает программа

Только **FC03, чтение**; команд управления и записи в прибор нет. `n` — выбранный канал весов, 1–3.

| Когда | Адрес / число регистров | Что читается |
|---|---|---|
| Один раз при установке связи; повторно после переподключения | **1000 / 9** | Тип M10, SN прибора, FW, время прибора и загрузки, порядок слов |
| Затем один раз; повторно после переподключения | **1100 + 33·(n−1) / 22** | SN весов, единица веса, тип и число диапазонов, Min/Max/d диапазонов |
| Циклически, с заданным периодом | **2000 + 33·(n−1) / 13** | Время измерения, Errors, статус стабильности/нуля, активный диапазон, текущая d, брутто, нетто, тара |

В журнале: **TX/RX** — запрос/ответ в HEX; **«Идентификация»**, **«Конфигурация»**, **«Данные»** — их расшифровка. Связь между строками — **номер прибора + № транзакции**. Фильтры **«Показания»** и **«Инициализация»** разделяют текущий вес и начальные запросы. Полный обмен сохраняется в `%LOCALAPPDATA%\M10MbTcp\logs\`; открыть его можно кнопкой **«Папка журналов»**.
