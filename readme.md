# M10 Modbus TCP Monitor

Демонстрационная программа для Windows: чтение показаний двух M10 по MODBUS TCP и сравнение с WEB-экраном приборов.

## v4.8: журнал и навигация

Номер перед временем — **общий сквозной номер транзакции журнала для двух приборов**, а не счётчик Modbus каждого устройства. Он назначается при первом появлении обмена и не сбрасывается при запуске второго прибора, перезапуске опроса или очистке экрана. TX, RX, HEX, расшифровка и связанные события имеют один номер и идут цельным блоком по порядку начала транзакций. Ответ более раннего обмена добавляется в его блок, а не между строками второго прибора. Системные и операторские события без транзакции остаются отдельными записями без номера.

Фильтры и ручной экспорт сохраняют эту группировку. Автоматический `traffic.txt` использует те же общие номера, но сохраняет фактический порядок поступления записей для диагностики времени обмена. Настоящий номер Modbus остаётся неизменным в первых двух байтах HEX.

При начале опроса первый регистр ответа **1000 / 9** обязательно проверяется: **100 = M10**. Другой тип останавливает опрос до исправления настроек и ручного перезапуска. Версия FW выводится справочно и не ограничивает подключение. Проверки целостности Modbus и корректности числовых данных сохранены. Событие **«Обмен установлен»** появляется сразу после корректного ответа идентификации M10, до запроса конфигурации и первых показаний; при восстановлении — «Обмен восстановлен».

**«Автопрокрутка»** управляет и основным журналом, и белыми полями событий обеих карточек. Она не приостанавливает опрос, обновление показаний и запись файлов. Один клик в журнале выделяет запись целиком (TX/RX — вместе с HEX); перетаскивание позволяет выделить произвольную часть текста. Выбор записи выключает автопрокрутку, чтобы новые записи не уводили от выбранного места.

При переключении фильтров выделение и прокрутка переходят к той же записи либо к записи того же обмена, если она есть в выбранном представлении. Одинаковые номера транзакций разных приборов, перезапусков и циклов счётчика не смешиваются. Клик по событию карточки открывает **«Все записи»**, снимает фильтр прибора и подсвечивает именно это событие. Экранные буферы ограничены; если запись уже удалена из буфера, она остаётся в файлах сессии.

Строки TX, RX и расшифровки начинаются с **`номер: время [Прибор N]`**; повторного «на запрос №» нет. При несовпадении номера ответа его фактический номер указывается отдельно. HEX: TX — зелёный, RX — более светлый зелёный; корректная расшифровка — голубая. Ошибки и предупреждения сохраняют отдельные цвета. Брутто, нетто, тара, d и Min/Max в расшифровке имеют **три дробных знака**, без повторного округления веса по d. Исходные HEX не изменяются.

Фильтр **«Показания»** отображает брутто, нетто, тару и d с полной значащей точностью исходного `float` (`G9`), без округления до трёх дробных знаков. «Расшифровка», «Все записи» и карточки сохраняют трёхзначное представление. При переходе между «Показаниями» и «Расшифровкой» выделяется тот же ответ прибора, несмотря на разную длину чисел. Ручной экспорт сохраняет текущее представление; автоматический `traffic.txt` сохраняет трёхзначное представление и неизменённые HEX.

Клик по событию **карточки** выделяет всю связанную транзакцию: TX и RX вместе с HEX, расшифровку и события этого обмена. Если между ними вклинились записи другого прибора, подсвечиваются только связанные фрагменты; кнопка «Копировать» и Ctrl+C копируют их без посторонних записей. Событие без транзакции выделяется отдельно. При смене фильтра сохраняется выбор транзакции. Клик **внутри журнала** снимает групповое выделение и выбирает одну запись (TX/RX — обе строки, заголовок и HEX). Перетаскивание по-прежнему позволяет выделить произвольный текст.

Имена папок сессий — **`yyyy-MM-dd_HH-mm-ss-fff`**, без случайного суффикса. При совпадении времени выбирается следующая свободная миллисекунда; существующие журналы не перезаписываются. Имя ручного экспорта по-прежнему — `M10_log_yyyyMMdd_HHmmss.txt`.

## Сборка и автономный EXE

**Microsoft Visual Studio Community 2022, версия 17.14** — [скачать с сайта Microsoft](https://visualstudio.microsoft.com/vs/older-downloads/). В установщике выбрать **«Разработка классических приложений .NET»** и **.NET 8 SDK**. Это Visual Studio, не Visual Studio Code.

Открыть в IDE файл **`M10Modbus.sln`**. Для обычной сборки выбрать **Release**, затем **Сборка → Собрать решение**; для запуска — **F5**.

Чтобы получить EXE для **Windows x64 без доустановки .NET**, открыть **Вид → Терминал** в Visual Studio и выполнить из папки решения:

```powershell
dotnet publish M10Modbus.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

Готовый файл — **`publish\M10Modbus.exe`**. Его можно перенести на другой ПК с Windows 10/11 x64: среда .NET включена в EXE. Обычная сборка через меню такой автономный EXE не создаёт.

## Подключение через VPN

**Адреса `10.0.1.8` и `10.0.1.18` зашиты по умолчанию для конкретного стенда:** программа предназначена для запуска при установленном VPN-подключении в локальную подсеть **из двух приборов M10 с этими адресами**. Это объявленные адреса данного стенда, а не универсальные адреса любых M10.

После подключения VPN проверить приборы последовательно:

1. В командной строке Windows:
   ```cmd
   ping 10.0.1.8
   ping 10.0.1.18
   ```
2. Открыть в двух окнах браузера **[https://10.0.1.8/](https://10.0.1.8/)** и **[https://10.0.1.18/](https://10.0.1.18/)**. Если для стенда выдан отдельный WEB-порт или путь, использовать выданный полный URL.
3. Запустить программу, проверить **IP, порт MODBUS (обычно 502), Id и канал весов**, затем нажать **«Начать опрос»** в каждой карточке. Номер карточки не является номером канала: если в каждом M10 одни весы, канал в обеих карточках — **1**. Все поля должны соответствовать настройкам приборов.

**Снимок для сравнения:** разместить рядом обе WEB-страницы (два окна браузера) и окно программы так, чтобы были видны показания всех трёх окон; сохранить общий снимок в PNG.

## Что читает программа

Только **FC03, чтение**; команд управления и записи в прибор нет. `n` — выбранный канал весов, 1–3.

| Когда | Адрес / число регистров | Что читается |
|---|---|---|
| Один раз при установке связи; повторно после переподключения | **1000 / 9** | Тип M10, SN прибора, FW, время прибора и загрузки, порядок слов |
| Затем один раз; повторно после переподключения | **1100 + 33·(n−1) / 22** | SN весов, единица веса, тип и число диапазонов, Min/Max/d диапазонов |
| Циклически, с заданным периодом | **2000 + 33·(n−1) / 13** | Время измерения, Errors, статус стабильности/нуля, активный диапазон, текущая d, брутто, нетто, тара |

В журнале: **TX/RX** — запрос/ответ в HEX; **«Идентификация»**, **«Конфигурация»**, **«Данные»** — их расшифровка. Связь между строками — **номер прибора + номер транзакции** в пределах одного сеанса опроса и цикла счётчика. Фильтры **«Показания»** и **«Инициализация»** разделяют текущий вес и начальные запросы. Полный обмен сохраняется в `%LOCALAPPDATA%\M10MbTcp\logs\`; открыть его можно кнопкой **«Папка журналов»**.
