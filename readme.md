# M10 Modbus TCP Monitor

Настольное приложение для мониторинга весоизмерительных приборов Микросим M10 по протоколу Modbus TCP.

Программа отображает текущие показания и состояние весов, отслеживает ошибки связи и сохраняет подробный журнал обмена. Поддерживается одновременный опрос двух приборов.

## Возможности

- Подключение к одному или двум приборам по IP-адресу и TCP-порту.
- Настройка Unit ID, номера весов, периода опроса и таймаута.
- Отображение веса брутто, нетто и тары в килограммах или тоннах.
- Просмотр брутто без округления и настройка числа знаков после запятой.
- Отображение стабильности, признака нуля и состояния «ниже Min1».
- Контроль ошибок прибора и автоматическое восстановление связи.
- Журнал запросов и ответов Modbus TCP в HEX с расшифровкой показаний.
- Фильтрация, копирование и сохранение журнала в файл.
- Сохранение настроек подключения между запусками.

## Интерфейс

Главное окно состоит из панели управления, карточек приборов и журнала обмена.

В карточке каждого прибора отображаются состояние подключения, текущий вес, статус измерения и история событий. Цвета помогают быстро заметить нестабильные показания, ошибки прибора или потерю связи.

Обе карточки устроены одинаково: у каждого прибора есть свой чек-бокс «Опрос», который включает и выключает опрос только этого прибора. Пока опрос включён, адрес, порт, Id, номер весов и «Без округления» заблокированы. Кнопка «Остановить всё» выключает опрос обоих приборов.

После выключения опроса или при потере связи карточка показывает последние полученные данные серым цветом с временем («последние данные на …») — живые цвета (зелёный/жёлтый) бывают только у свежих показаний.

Границу между карточками и журналом можно перетаскивать мышью; высота карточек, размер и положение окна сохраняются между запусками.

Журнал содержит полные Modbus TCP-запросы и ответы, адрес начала группы регистров, количество слов и расшифровку полученных данных. Кнопка Clear очищает отображаемые записи, Hold фиксирует журнал на экране для просмотра.

## Журнал

Пример записи обмена:

```
21:47:31.420 [Прибор 1] TX №4 Id=1 FC=03 адрес=2000 (0x07D0) регистров=13 (0x000D) · показания · период 250,0 мс
                         00 04 00 00 00 06 → 01 03 07 D0 00 0D
21:47:31.446 [Прибор 1] RX №4 Id=1 FC=03 байт данных=26 (0x1A) · на запрос №4 · ответ через 25,8 мс
                         00 04 00 00 00 1D → 01 03 1A …
```

Обозначения (легенда также пишется в начало каждого журнала):

- **№** — номер транзакции Modbus TCP; одинаков в запросе и ответе на него.
- **Id** — адрес устройства (Unit Identifier, 7-й байт кадра, как адрес в Modbus RTU).
- **FC** — код функции; адрес и число регистров — десятичные (в скобках hex), адреса как в документации прибора.
- **HEX** — слева от `→` 6 байт TCP-префикса (№, протокол 0, длина), справа Id + PDU (то же, что кадр RTU без CRC).
- **период** — время от предыдущего запроса показаний этого прибора; если период не выдерживается, добавляется «ПРЕВЫШЕН (задан N мс)».
- **ответ через** — время от отправки запроса до последнего байта ответа.
- **ИНИЦИАЛИЗАЦИЯ** — чтение идентификации (1000) и конфигурации весов (1100…) при подключении и после восстановления связи; выполняется подряд, без выдержки периода. Период задаётся только между запросами показаний.

## Требования

- Windows 10 или Windows 11.
- .NET 8 SDK — для сборки и запуска из исходного кода.
- Сетевой доступ к прибору M10.
- Visual Studio с поддержкой разработки классических приложений .NET — при работе через IDE.

## Запуск

Откройте решение `M10Modbus.sln` в Visual Studio, соберите и запустите проект `M10Modbus`.

Или выполните из каталога проекта:

dotnet run --project M10Modbus.csproj


## Начало работы

1. Задайте период опроса и таймаут на верхней панели.
2. В карточке прибора укажите IP-адрес, порт, Id и номер весов.
3. Отметьте чек-бокс «Опрос» в этой карточке. Второй прибор включается так же — своим чек-боксом «Опрос», независимо от первого.
4. Снимите «Опрос», чтобы остановить прибор, или нажмите «Остановить всё».
5. Следите за показаниями и состоянием связи; при необходимости откройте или сохраните журнал обмена.

Порт по умолчанию — 502. Фактические параметры подключения должны соответствовать настройкам прибора и сети.

## Файлы журналов

Журналы сессий сохраняются в:
%LOCALAPPDATA%\M10MbTcp\logs\

Папку текущей сессии также можно открыть из интерфейса. В ней находятся общий журнал обмена и журналы событий приборов.

## Протокол

При подключении программа считывает информацию о приборе и конфигурацию весов, включая единицы измерения и порядок слов для 32-битных значений. Затем выполняется циклическое чтение текущих показаний.

Реализована функция **FC03 — чтение группы регистров**. Программа предназначена для мониторинга и не отправляет команды управления прибором.

```
M10Modbus/
├── M10Modbus.sln             # Решение: приложение и библиотека Core
├── M10Modbus.csproj          # Приложение WinForms (net8.0-windows)
├── Program.cs                # Точка входа приложения
├── MainForm.cs               # Интерфейс: окно, карточки приборов, журнал
├── Core/                     # Логика без WinForms (net8.0)
│   ├── M10Modbus.Core.csproj
│   ├── M10ModbusClient.cs    # Подключение и обмен по Modbus TCP (FC03)
│   ├── TraceFormatter.cs     # Форматы строк журнала (TX/RX/данные/события)
│   ├── DeviceCardModel.cs    # Состояние карточки прибора, фиксация ошибок
│   ├── PollScheduler.cs      # Выдержка периода между запросами показаний
│   ├── TimerResolution.cs    # Точность системного таймера Windows
│   ├── SessionJournal.cs     # Файлы журнала сессии
│   └── AppSettings.cs        # Настройки (settings.json)
└── tests/                    # Автотесты библиотеки Core
```
