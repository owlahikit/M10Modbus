# M10 Modbus TCP Monitor

Настольное приложение для мониторинга весоизмерительных приборов Микросим M10 по протоколу Modbus TCP.

Программа отображает текущие показания и состояние весов, отслеживает ошибки связи и сохраняет подробный журнал обмена. Поддерживается одновременный опрос двух приборов.

## Возможности

- Подключение к одному или двум приборам по IP-адресу и TCP-порту.
- Настройка Unit ID, номера весов, периода опроса и таймаута.
- Отображение веса брутто, нетто и тары в килограммах или тоннах.
- Просмотр брутто без округления и настройка числа знаков после запятой.
- Отображение стабильности, признака нуля и состояния «ниже Min1».
- Контроль ошибок прибора и автоматическое восстановление связи.
- Журнал запросов и ответов Modbus TCP в HEX с расшифровкой показаний.
- Фильтрация, копирование и сохранение журнала в файл.
- Сохранение настроек подключения между запусками.

## Интерфейс

Главное окно состоит из панели управления, карточек приборов и журнала обмена.

В карточке каждого прибора отображаются состояние подключения, текущий вес, статус измерения и история событий. Цвета помогают быстро заметить нестабильные показания, ошибки прибора или потерю связи.

Журнал содержит полные Modbus TCP-запросы и ответы, адрес начала группы регистров, количество слов и расшифровку полученных данных. Кнопка Clear очищает отображаемые записи, Hold фиксирует журнал на экране для просмотра.

## Требования

- Windows 10 или Windows 11.
- .NET 8 SDK — для сборки и запуска из исходного кода.
- Сетевой доступ к прибору M10.
- Visual Studio с поддержкой разработки классических приложений .NET — при работе через IDE.

## Запуск

Откройте проект `M10Modbus.csproj` в Visual Studio, соберите и запустите его.

Или выполните из каталога проекта:

dotnet run --project M10Modbus.csproj


## Начало работы

1. Укажите IP-адрес, порт и Unit ID прибора.
2. При необходимости выберите номер весов и включите второй прибор.
3. Задайте период опроса и таймаут.
4. Нажмите «Начать опрос».
5. Следите за показаниями и состоянием связи; при необходимости откройте или сохраните журнал обмена.

Порт по умолчанию — 502. Фактические параметры подключения должны соответствовать настройкам прибора и сети.

## Файлы журналов

Журналы сессий сохраняются в:
%LOCALAPPDATA%\M10MbTcp\logs\

Папку текущей сессии также можно открыть из интерфейса. В ней находятся общий журнал обмена и журналы событий приборов.

## Протокол

При подключении программа считывает информацию о приборе и конфигурацию весов, включая единицы измерения и порядок слов для 32-битных значений. Затем выполняется циклическое чтение текущих показаний.

Реализована функция **FC03 — чтение группы регистров**. Программа предназначена для мониторинга и не отправляет команды управления прибором.
