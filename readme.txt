M10 Modbus TCP Monitor

Демонстрационная программа для Windows: чтение показаний двух M10 по MODBUS TCP и сравнение с WEB-экраном приборов.

Сборка и автономный EXE

Microsoft Visual Studio Community 2022, версия 17.14.
Скачать: https://visualstudio.microsoft.com/vs/older-downloads/
В установщике выбрать Разработка классических приложений .NET и .NET 8 SDK.

Visual Studio/Visual Studio Code/Rider...

Открыть файл M10Modbus.sln. Выбрать Release, затем меню Сборка, Собрать решение.
Для запуска из IDE нажать F5.

Для получения EXE для Windows x64 без доустановки .NET (это проект на .NET 8 SDK) открыть меню Вид, Терминал и выполнить из папки решения:

dotnet publish M10Modbus.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish

Готовый файл: \M10Modbus.exe.
Его можно перенести на ПК с Windows 10/11 x64: среда .NET включена в EXE.
Обычная сборка через меню такой автономный EXE не создаёт.

Подключение через VPN

Адреса 10.0.1.8 и 10.0.1.18 зашиты по умолчанию для конкретного стенда.
Программу запускать при установленном (VPN-)подключении в локальную подсеть из двух приборов M10 с этими адресами.
Это объявленные адреса данного стенда, см. ваши адреса M10.

После подключения VPN проверить приборы последовательно.

1. В командной строке Windows выполнить:
ping 10.0.1.8
ping 10.0.1.18

2. Открыть в двух окнах браузера:
https://10.0.1.8:8443
https://10.0.1.18:8443
Порт 8443 относится к WEB-интерфейсу, а не к MODBUS.

3. Запустить программу. Проверить IP, порт MODBUS (обычно 502), Id и канал весов.
Нажать Начать опрос в каждой карточке.
Номер карточки не является номером канала: если в каждом M10 одни весы, канал в обеих карточках
Все поля должны соответствовать настройкам приборов.

Для сравнения разместить рядом две WEB-страницы и окно программы - удостовериться в правильном отображении подключений.

Что читает программа

FC03, чтение. Команд управления и записи в прибор нет.
n в формулах ниже означает выбранный канал весов от 1 до 3.

1. Один раз при установке связи: адрес 1000, 9 регистров.
Тип M10, SN прибора, FW, время прибора и загрузки, порядок слов.

2. Затем один раз: адрес 1100 + 33*(n-1), 22 регистра.
SN весов, единица веса, тип и число диапазонов, Min/Max/d диапазонов.
После переподключения оба начальных запроса повторяются.

3. Циклически с заданным периодом: адрес 2000 + 33*(n-1), 13 регистров.
Время измерения, Errors, статус стабильности и нуля, активный диапазон, текущая d, брутто, нетто, тара.

В журнале TX и RX означают запрос и ответ в HEX.
"Идентификация", "Конфигурация" и строки показаний содержат расшифровку.
Связь между строками: номер прибора и номер транзакции.
Фильтры "Показания" и "Инициализация" разделяют текущий вес и начальные запросы.
Автопрокрутку журнала можно включать и выключать вручную; опрос и запись в файл продолжаются.
При выключенной автопрокрутке строки можно выделять мышью во время опроса.
В событиях карточки при изменении состояния указан актуальный вес брутто.
Полный обмен сохраняется в *\logs\.
Открыть папку можно кнопкой "Папка журналов".

Индикация: ниже Min1 красный индикатор первой строки; выше последнего Max загорается индикатор над диапазонами.
Превышение Max не означает аварию: её определяет поле Errors, полученное от прибора.
При аварии сохраняется серая таблица с надписью Авария; тара показывается последней корректной, не как новое измерение.
После снятия аварии включённая фиксация отображается как Фиксация Аварии с кодом; без фиксации вес возвращается сразу.
Галочка фиксации применяется сразу к обоим приборам; при её снятии локальная фиксация сбрасывается.
Для стенда Errors=0x0002 расшифрован как ниже порога по сравнению с WEB, вопреки карте от 22.10.2026.
Errors=0x0004 означает нагрузку выше порога по проверке на стенде. Исходные HEX не меняются.
